# juegodecombate
Este proyecto desarrolla el juego de combate en TypeScript utilizando programación orientada a objetos. Para instalar y correr el juego:

Clonar el repositorio: git clone (https://github.com/JuanPabe/Super-Tetris-V1.git)

Para instalar las dependencias: npm install

Para poder correr los tests: npm test

Para poder ver la cobertura: npm run coverage
